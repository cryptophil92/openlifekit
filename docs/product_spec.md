# Product specification

## Name

OpenLifeKit

## Goal

Create an open source, privacy-first and offline-first mobile application for Android and iOS that helps users keep essential life and emergency information locally available.

## MVP v0.1.0

- Onboarding without account.
- Optional profile.
- Emergency card with explicit sharing preferences.
- Important contacts.
- Important document metadata.
- Local reminders.
- Practical checklists.
- Local JSON export/import.
- Settings, privacy, license and data deletion.

## Excluded from MVP

- Mandatory account.
- Backend.
- Cloud sync.
- Analytics.
- Document scan/OCR.
- File/photo storage.
- Paid features.
