# Local setup

## Clone

```bash
git clone https://github.com/cryptophil92/openlifekit.git
cd openlifekit
git checkout develop
```

## Current platform status

The Android platform folder is generated and committed.

iOS still requires a macOS workstation with Flutter and Xcode. Generate it from a Mac when the iOS pass starts:

```bash
flutter create --org org.openlifekit --project-name open_life_kit --platforms ios .
```

## Verify

```bash
flutter pub get
flutter analyze
flutter test
flutter build apk --debug
```

## Windows Android environment used for validation

The first Android bootstrap was validated from a Windows workstation with:

- Flutter stable.
- Git.
- Android Studio.
- Android SDK installed in a path without spaces.
- Android licenses accepted.

## Notes

Generated Flutter localization Dart files are ignored because they are regenerated by Flutter from the localization inputs.
