# Code of Conduct

OpenLifeKit contributors are expected to keep the project respectful, constructive and welcoming.

## Expected behavior

- Be respectful and professional.
- Focus on the project and the user impact.
- Assume good intent while staying clear and precise.
- Respect privacy and security concerns.

## Unacceptable behavior

- Harassment or discriminatory language.
- Publishing private information.
- Sharing exploit details irresponsibly.
- Adding tracking or privacy-invasive behavior without explicit project approval.

## Enforcement

Maintainers may moderate issues, pull requests and discussions to protect the project and its contributors.
